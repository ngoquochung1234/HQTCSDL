# HQTCSDL · Aurora Cruise

Các mốc dự án trong repository:

- `phien-ban-50/`: đăng nhập/phân quyền, chuyến và lịch trình.
- `phien-ban-70/`: bổ sung hoạt động, đăng ký/check-in, tour bờ và POS; chưa mở tài chính, báo cáo vận hành và quản trị đầy đủ.
- `phien-ban-100/`: đầy đủ chức năng theo nguồn dự án gốc, gồm tài chính, báo cáo và quản trị.
- `week1-cruise-foundation/`: phiên bản làm việc chính của tuần 1.

Mỗi mốc có README riêng về cách chạy và phạm vi chức năng. Các bản dùng database độc lập để không ảnh hưởng dữ liệu của nhau.
